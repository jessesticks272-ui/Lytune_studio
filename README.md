# Lytune Studio 🌊

Lytune Studio is a futuristic Gen-Z inspired Afrobeat beat-selling and music discovery landing page.

Built with:
- HTML5
- CSS3
- SVG Logo Design
- Modern Glassmorphism UI
- Animated Background Effects


# ✨ Features

- Animated futuristic landing page
- Responsive mobile design
- Floating glass UI cards
- Afrobeat / Amapiano inspired aesthetic
- Custom SVG logo
- Smooth hover animations
- Dynamic gradient background
- Gen-Z style interface
